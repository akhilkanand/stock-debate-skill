# stock-debate

A [Claude Code](https://claude.com/claude-code) skill that runs a structured Bull vs Bear debate on an Indian listed stock (NSE/BSE).

Five roles, each a separate subagent that does its own web research:

1. **Researcher** builds a neutral fact sheet: segments, 5-year financials, latest quarter, concall guidance, shareholding, valuation vs history and peers. Banks and NBFCs get lender metrics (NIM, credit cost, GNPA, CASA, CRAR, P/ABV) instead of EBITDA and cash flow.
2. **Bull** makes the strongest case for the stock.
3. **Bear** makes the strongest case against it and rebuts the Bull.
4. **Rebuttal rounds** (2 by default): each side attacks the other's latest claims with fresh data and concedes what's true.
5. **Judge** (a CIO) scores who argued better, lists open questions, gives a 1–10 conviction score and the monitorables that would change the view.

Every figure is cited with its period and source, and anything not found is marked "not found" rather than guessed. The full transcript is saved as `debate_<Company>_<YYYY-MM-DD>.md` in your working directory.

**See a sample:**
- [examples/tata-motors.md](examples/tata-motors.md): a trimmed run on Tata Motors that shows the skill handling the 2025 demerger into two listed companies.
- [examples/varun-beverages.md](examples/varun-beverages.md): a trimmed run on Varun Beverages with 4 rebuttal rounds, where a quality business meets a high multiple.

## Install

**Easiest:** paste this into Claude Code:

```
Install the stock-debate skill from https://github.com/akhilkanand/stock-debate-skill: clone the repo to a temp folder, copy skills/stock-debate into ~/.claude/skills/, then delete the clone.
```

Then start a new session (or restart Claude Code) so it picks up the skill.

**Manually:** copy the skill folder into your Claude Code skills directory:

```bash
git clone https://github.com/akhilkanand/stock-debate-skill.git
```

```bash
mkdir -p ~/.claude/skills && cp -r stock-debate-skill/skills/stock-debate ~/.claude/skills/
```

For a single project instead, copy it to `.claude/skills/` inside that project.

## Use

```
/stock-debate Tata Motors
/stock-debate ICICI Bank 3
```

The optional number sets the rebuttal rounds (default 2).

Needs web search and fetch enabled. Expect a run to take roughly 15–25 minutes and use several hundred thousand tokens, since each role researches independently.

## Disclaimer

The output is an educational discussion generated by an AI model from public web sources, which may be incomplete, outdated or wrong. It is not investment advice or a research report. Check the numbers against primary filings before relying on them.
